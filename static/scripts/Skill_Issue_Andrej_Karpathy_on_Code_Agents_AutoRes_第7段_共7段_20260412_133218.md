接下来，## **关于智能体网络与人类角色的思考**

我觉得智能体网络这个概念还比较新，目前还没有什么成熟的机制。但我想举一个例子来说明未来可能发生的情况。

有一本很好的书，也许能带来一些启发，书名叫《Demon》。你可能读过，书里讲的是“达蒙智能”。它最终在某种意义上，有点像在“操纵”人类。你看，人类某种程度上成了它的“执行器”，但同时也是它的“传感器”。

所以，我认为整个社会会以某种方式重塑，以适应并服务于这种……嗯，这种模式。这将在整个行业内普遍发生。是的，自动化程度会大大提高，并产生某些特定的需求。而人类，将去服务那个机器的需求，而未必是直接服务彼此的需求。

## **关于微型GPT项目**

**>>** 我想在结束前聊聊你的一个小小副业项目。跟我说说“微型GPT”吧。

**>>** 哦，好的。微型GPT。是这样的，我大概有十年、二十年的一个持续执念，就是简化和提炼大语言模型，嗯，基本上就是把大语言模型提炼到它们最本质的核心。我做过一系列这方面的项目，比如Nano GPT，还有Make More，嗯，以及微型GPT、Micrograd等等。

所以我觉得微型GPT现在是我试图将其提炼到本质的“最新成果”。因为训练神经网络，特别是大语言模型，嗯，涉及大量的代码，但所有这些代码的复杂性其实都来自于效率。

**>>** 只是因为你需要它跑得快。如果你不需要它快，只关心算法本身，那么这个算法实际上就是200行Python代码，非常易读，这还包括了注释和所有内容。

嗯，因为你只需要你的数据集，它是一段文本，嗯；你需要你的神经网络架构，大概50行；你需要做前向传播，然后你需要做，嗯，反向传播来计算梯度。所以一个小小的自动求导引擎来计算梯度，大概100行；然后你需要一个优化器，比如Adam，这是一个非常先进的优化器，实际上也就10行左右。所以把所有东西放在一个训练循环里，是的，就是200行左右。

我觉得有意思的是，要是在大概一年前或更早，如果我做出了微型GPT，我可能会很想给大家解释，比如录个视频一步步讲解之类的。嗯，我实际上也尝试做过一点那个视频，我试着写个小指南等等。但我有点意识到，这并没有增加太多价值，因为人们……因为它已经如此简单，只有200行，任何人都可以让他们的智能体以各种方式解释它。而智能体……我不再是向人解释了，我是在向智能体解释。

如果你能向智能体解释清楚，那么智能体就可以充当路由器，它们实际上可以用人类的语言，以无限的耐心，根据对方的能力水平来定向解释。

**>>** 没错。如果我不理解某个特定的函数，我可以让智能体用三种不同的方式解释给我听，而我不可能从你那里得到这个。

**>>** 正是如此。所以我有点觉得，你知道什么是教育吗？它过去是指南，是讲座，是这么回事。但我感觉现在更多时候，我是在向智能体解释事情，也许我正在开发一些技能，嗯……

嗯，所以基本上，技能只是一种指导智能体如何教授某个东西的方法。所以也许我可以为微型GPT设计一个技能，设想一下如果对方对理解代码库感兴趣，智能体应该带你经历的学习路径。这只是给模型的一些提示，比如“哦，先从这开始，然后到那”。我可以把课程大纲稍微编排一下，作为一种技能。

嗯，所以，嗯，我觉得直接向人解释事情会越来越少，而更多会变成：智能体理解了吗？如果智能体理解了，它们就会去做解释。我们还没有完全达到那个阶段，因为它们……我仍然觉得我可能比智能体解释得稍微好一点，但我仍然觉得模型改进得如此之快，以至于，嗯，在某种程度上这是一场必输的战斗。

嗯，所以我认为教育将会因此被相当彻底地重组，嗯，这几乎意味着相互教学这种模式的终结。就像，如果我有一个代码库之类的，过去你需要为使用你库的其他人编写文档。但现在你不应该再那样做了，你应该为智能体准备Markdown文档，而不是为人类准备HTML文档。因为如果智能体理解了，它们就能解释所有不同的部分。所以这是一种通过智能体的“转述”，你知道，嗯，就是这样。所以我认为我们会看到更多这样的情况上演。

**>>** 好吧，我们看看伟大的教师们是否知道如何培养向智能体解释事物的直觉，这会有所不同。

**>>** 最终，举个例子，微型GPT。我问过，我尝试让一个智能体来写微型GPT。我告诉它，试着把最简单的东西提炼出来，试着把神经网络提炼到最简单的形式，但它做不到。微型GPT就像是我……这是我执念的终点。这就是那200行代码。我为此思考了很长时间，我为此着迷了很长时间。这就是解决方案。相信我，它不能再简单了。这就是我的价值所在。其他的一切，智能体都能理解。

**>>** 它只是无法自己想出来。但它完全理解，并且明白为什么以某种方式实现等等。所以我的贡献有点像就是这几点，但除此之外的所有教育部分，就不再是我的领域了。所以，也许是的，教育就是以这些方式改变，你必须注入你坚信的那几点，关于课程大纲，或者更好的解释方式之类的。智能体做不到的事情，现在就是你的工作。智能体能做的事情，它们可能比你做得更好，或者很快就能。所以你应该，嗯，战略性地思考你实际上应该把时间花在什么上。
