接下来，## **AI模型的分化与“物种形成”**

在大自然里，有些动物为了适应特定的生态位，会进化出过度发达的视觉皮层或其他特定器官。我认为，在AI模型领域，我们也应该能看到更多的“物种形成”。

我们并不需要一个全知全能的“神谕”模型。你可以让它“分化”，然后把它放到一个特定的任务上。我们应该能看到一些这样的例子，因为你应该能够拥有**更小的模型**，它们仍然保留着核心的认知能力，依然很能干，但它们会专门化。然后，它们就能在**延迟或吞吐量**方面，在你真正关心的特定任务上变得更高效。

举个例子，如果你是一个在Lean里工作的数学家。我看到，确实有一些版本是专门针对这个领域开发的。所以，未来可能会有一些这样的例子，这种“解绑”是有意义的。

这个问题说得通。我想，我纠结的地方在于，我认为我们**还没有看到太多的物种形成**，对吧？

确实，尽管模型本身已经面临压力，但显然存在一种压力，比如“做一个好的代码模型，然后把它重新合并回主干”。

我想，也许有很多非常短期的供应短缺，这可能导致了现在更多的物种形成。

我认为，**操纵模型“大脑”的科学还没有完全发展成熟**。

你指的是什么“操纵”？

但我想，如果……我认为，如何更深入地调整模型，如何实现持续学习，或者如何在某个特定领域进行微调、如何在一个特定领域变得更好，或者如何真正触及权重，而不仅仅是上下文窗口，这更像是一门正在发展的科学。所以，**直接触及权重比仅仅操作上下文窗口要棘手得多**。因为你实际上是在从根本上改变整个模型，并可能改变其智能。

所以，也许这只是一门尚未完全发展的科学，关于物种形成的科学。而且，这种分化还必须足够廉价，才能在特定情境下值得去做。

## **构建可信与不可信工作者的协作系统**

举个例子，在自动研究中，你只是想找到一段能将模型训练到验证损失非常低的代码。如果有人给你一个候选提交，验证这个提交是否正确、是否优秀是非常容易的。比如，互联网上可能有人声称这段代码能优化得更好，给你更好的性能。你可以很容易地检查。但可能很多工作都花在了检查上。不过从根本上说，他们可能会撒谎，等等。

所以，你基本上在处理一种类似的情况……它看起来有点像我的设计，那些设计**整合了一个不可信的工作者池**，实际上看起来有点像区块链。因为不是区块，而是提交，这些提交可以相互构建，它们包含了改进代码的变更。而“工作量证明”基本上就是进行大量实验，以找到有效的提交。

这很难。而目前的奖励只是登上排行榜。现在没有任何金钱奖励。但我不想把这个类比推得太远，但它根本上存在这个问题：**大量的搜索投入其中，但验证一个候选解决方案确实有效却非常廉价**，因为你只需要训练一次。有人可能尝试了一万个想法，但你只需要检查他们产出的那个东西是否真的有效，因为其他九千九百个都没用。

所以，长话短说，就是你必须想出一个系统，让**不可信的工作者池能与可信的工作者池协作**，可信的工作者负责验证。整个事情是异步的，可以运作，等等。而且从安全角度看，它是安全的，因为如果有人给你任意代码，而你要运行它，那是非常可疑和不靠谱的。

但根本上说，这应该是完全可能的。所以你熟悉像SETI@home和Folding@home这样的项目，所有这些问题都有类似的设置。在Folding@home里，你是在折叠蛋白质，找到一个低能量的构型非常难。但如果有人找到了一个他们评估为低能量的构型，那就完美了，你可以直接使用，很容易验证。

所以，很多事情都有这个特性：**产生（解决方案）非常昂贵，但验证非常廉价**。因此，在所有那些情况下，像Folding@home、SETI@home或“自动研究@home”都会是很好的契合点。

## **分布式智能体协作的潜力**

所以，长话短说，**互联网上的一群智能体可以协作改进大语言模型**，甚至可能**超越前沿实验室**。谁知道呢？嗯，是的，也许这甚至是可能的。前沿实验室拥有大量可信的计算资源，但地球要大得多，拥有海量的不可信计算资源。但如果你建立了处理这个问题的检查机制，那么也许互联网上的群体有可能想出更好的解决方案，人们会为他们关心的事情贡献计算周期。

所以，抱歉，最后一个想法是，很多公司或机构可能有他们自己关心的事情。如果你有计算能力，你可以贡献给不同类型的自动研究轨道。比如，你关心某种特定类型的癌症，你不只是给某个机构捐款，你实际上可以购买计算资源，然后加入那个项目的自动研究论坛。
