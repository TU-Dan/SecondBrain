它扫描了局域网，找到了Sonos系统。结果发现，Sonos系统没有任何密码保护之类的措施。我就直接登录进去了，系统显示：“哦，是的，你安装了这些Sonos系统。” 然后我就想试着逆向分析一下它是怎么工作的。

它对灯光系统也做了同样的事。基本上，它就像是“黑”了进去，搞清楚了整个系统。它创建了API，创建了一个仪表板，这样我就能看到一个类似指挥中心的东西，能看到家里所有的灯。然后它就开始开关灯了。

所以，我可以在“睡觉时间”命令它。当我说“睡觉时间”，意思就是所有灯都关掉，诸如此类。所以，它控制着我所有的灯、暖通空调系统、窗帘、游泳池、水疗池，还有我的安防系统。

我有一个摄像头对着房子外面。任何时候有人开车进来，我有一个Quinn模型会查看视频。首先，有变化检测，对吧？

**（对话者A）** 然后基于变化检测，它会传给Quinn模型，接着它实际上会给我发WhatsApp消息。它会显示一张外面的图片，然后说：“嘿，一辆联邦快递卡车刚刚开过来了。联邦快递卡车刚刚开过来，你可能想查看一下，或者你可能收到邮件了之类的。” 然后“多比”就会给我发这条非常棒的消息。

所以我觉得，我甚至还没有完全推动这个范式，但仅仅这样就已经非常有帮助、非常鼓舞人心了。

## **用户期望与软件的未来**

**（对话者A）** 你觉得这是否表明了人们从用户体验角度对软件的期望？因为我觉得，人们往往忽略了，人类需要付出努力去学习新软件、新界面。

**（对话者B）** 是的，我认为在某种程度上这是对的。这就像是根据人们对AI应该如何运作的期望来反向工作。因为人们心目中的AI形象，实际上并不是大语言模型（LLM）的原始形态。从原始意义上讲，LLM是一个令牌生成器，你知道，就是输出更多令牌。但他们想象中的是一个有身份的角色，你可以告诉它事情，它会记住，你知道，它就像是WhatsApp背后的一个实体。这更容易理解得多。

**（对话者A）** 嗯。

**（对话者B）** 所以我认为，在某种程度上，这就像是匹配人类对AI行为方式的既有期望，但在底层，有很多技术细节来实现这一点，而LLM作为一种原始工具，对于大多数人来说，还不足以真正“符合”他们对AI的想象，如果这说得通的话。

**（对话者A）** 是的。嗯，我觉得这就是我们理解AI是什么的方式，以及把它描述为“多比”或某种人格，显然更能引起人们的共鸣。

我也认为，你对你六个不同的家庭自动化软件系统所做的统一，引出了另一个问题：人们真的想要我们今天拥有的所有这些软件吗？

**（对话者B）** 是的。我认为有这样一种感觉，就是应用商店里那些用于使用智能家居设备等等的应用，在某种意义上甚至不应该存在。难道不应该只是API吗？难道不应该让智能体直接使用它们吗？难道我不能做各种家庭自动化的事情，而任何单个应用都无法做到吗？一个大语言模型实际上可以驱动工具，调用所有正确的工具，做相当复杂的事情。

**（对话者A）** 所以在某种意义上，这确实指向了这一点：也许存在大量定制化、专门化的应用过度生产，而这些应用本不应该存在，因为智能体在某种程度上“瓦解”了它们。一切都应该更像是暴露的API端点，而智能体是连接所有部分的智能“粘合剂”。

**（对话者B）** 嗯，另一个例子是我的跑步机。我的跑步机有一个应用，我想记录我做有氧运动的频率。但我不想登录一个网页界面，走一遍流程等等。所有这些都应该只是让API可用，这有点像是朝着智能体优先的工具或类似的方向发展。

所以我认为，整个行业必须以多种方式重新配置，以至于客户不再是人类了。而是代表人类行事的智能体，这种重构在某种意义上可能是巨大的。

## **自动研究的动机**

**（对话者B）** 自动研究的动机是什么？

**（对话者A）** 自动研究。是的。所以我想，我之前发过一条推文，大意是说，为了充分利用现在可用的工具，你必须**把自己从瓶颈中移除**。你不能在那里去提示下一件事。你需要把自己移出循环。你必须安排事情，让它们完全自主运行，你如何最大化你的令牌吞吐量，而不是身处循环之中。这就是目标。

所以我提到，现在的游戏规则是**增加你的杠杆作用**。我只需要偶尔投入很少的令牌，然后就有大量的事情代表我发生。所以自动研究，就像我发推文说的，我觉得人们喜欢它等等，但他们可能没有仔细思考过其中的含义。对我来说，自动研究就是这种含义的一个例子。

**（对话者B）** 你对它的效果感到惊讶。

**（对话者A）** 是的，我没想到它会起作用。因为我有项目DataChat，从根本上说，我觉得很多人对我痴迷于训练GPT-2模型等等感到非常困惑。但对我来说，训练GPT模型等等只是训练LLM的一个小工具、一个小游乐场。我真正更感兴趣的是**递归自我改进**这个想法，以及你实际上能在多大程度上让LLM改进LLM。

因为我认为所有前沿实验室都在做这件事，原因很明显。他们都在尝试递归地自我改进，大致来说。所以对我来说，这有点像是一个小沙盒。我猜我已经手动调整Namat很多了，用我习惯的老式方法。我是一个研究员，我做这个已经大概二十年了，我有一定量的……嗯……

**（对话者B）** 嗯，是的。

**（对话者A）** 好吧，我有大约二十年的经验，哦，我训练这个模型可能有几千次了。所以我做了一堆实验，我做过超参数调优，我做过所有的事情，我非常习惯，而且我做了二十年，我已经达到了一定的水平。我以为它已经调整得相当好了。

然后我让自动研究运行了一晚上，它带回来了一些我没有想到的调优设置。是的，我确实忘了价值嵌入的权重衰减，我的Adam优化器的beta参数也没有充分调优。这些东西是相互作用的。所以一旦你调整了一件事，其他事情可能也需要改变。

你知道，我不应该成为瓶颈。我不应该运行这些超参数搜索优化。我不应该查看结果。在这个案例中有客观标准。所以你只需要安排好，让它能一直运行下去。

所以这是自动研究的一个版本，一个试图改进的单一循环。我很惊讶它找到了这些东西。你知道，代码库已经调整得相当好了，但它仍然有所发现。而这只是一个单一循环。像这些前沿实验室，他们有数万个GPU集群。所以很容易想象，你将如何在较小的模型上实现大量这种自动化。
