# 乔布斯斯坦福演讲：点亮人生低谷

**生成时间**: 2026-04-19 15:57

---

（开场音乐渐入，然后降低为背景音）

大家好，欢迎收听本期播客。今天，我想和大家分享一段对我个人，也对无数人产生过深远影响的声音。它来自2005年，史蒂夫·乔布斯在斯坦福大学那场著名的毕业典礼演讲。很多人说，每当人生陷入迷茫或低谷时，听听这段讲话，总能重新获得力量。今天，我们就一起来重温这场演讲的精髓，看看这三个简单却深刻的故事，能给我们带来怎样的启示。

**第一个故事：关于生命中的点点滴滴**

乔布斯一上来就说，他没从大学毕业，所以这次算是他离大学毕业最近的一次。他要讲的第一个故事，是关于如何**串联生命中的点滴**。

他退学了。从里德学院只读了六个月就决定离开。为什么？原因可以追溯到他出生之前。他的生母是一位年轻的未婚研究生，她坚持要让乔布斯被有大学学历的夫妇收养。本来一切安排妥当，一对律师夫妇准备收养他。但当他出生时，那对夫妇最后一刻决定：他们想要个女孩。

于是，电话在深夜打到了另一对夫妇那里，也就是乔布斯后来的养父母。他们只是普通的工薪阶层，父亲甚至连高中都没毕业。生母起初拒绝签字，直到养父母承诺“一定让这孩子上大学”，她才同意。

十七年后，乔布斯真的上了大学。他天真地选了一所和斯坦福一样昂贵的学校，几乎花光了父母所有的积蓄。但读了六个月后，他感到迷茫：他不知道这辈子想干什么，也不知道大学如何能帮他找到答案，却在这里消耗父母一生的积蓄。于是，他决定退学。

**这个决定在当时非常可怕**，但回头看，却是他人生中最棒的决定之一。退学后，他不用再去上那些不感兴趣的必修课，而是可以溜去听那些真正吸引他的课程。日子并不浪漫：他睡在朋友房间的地板上，靠捡5美分一个的可乐瓶换钱买吃的，每周日晚上步行七英里穿过城镇，只为去克利须那神庙吃一顿像样的饭。

然而，正是凭着好奇心和直觉，他误打误撞学到了许多后来价值连城的东西。一个经典的例子是**书法课**。里德学院当时有全美最好的书法课程。校园里每张海报、每个抽屉标签上的字都优美手写。因为退学了，乔布斯决定去旁听这门课。他学习了衬线字体和无衬线字体，学习了如何调整字母组合间的间距，体会到了精妙排印的艺术之美。这门课在当时看来，**毫无实际应用的可能**。

但十年后，当他和团队设计第一台麦金塔电脑时，这一切知识都回来了。他们把这些优美的字体设计全部融入了Mac。Mac成为了第一台拥有精美字体的电脑。如果乔布斯当年没有退学，就不会去旁听那门书法课；如果没听过那门课，个人电脑可能就不会有今天我们习以为常的多样字体和比例间距。

**乔布斯由此得出他最重要的感悟之一：你无法预知未来，只能事后回顾，才能将生命中的点滴串联起来。** 所以你必须相信，这些点滴在未来总会以某种方式连接起来。你必须有所相信——无论是你的直觉、命运、生命还是因果。这种信念会给你勇气，去追随自己的内心，哪怕它会带你离开常规的道路。而这，将会造就一切的不同。

**第二个故事：关于爱与失去**

乔布斯是幸运的，他很早就找到了所爱的事业。20岁时，他和沃兹在父母的车库里创立了苹果公司。他们拼命工作，十年后，苹果从车库里的两个人，成长为拥有四千名员工、价值二十亿美元的公司。他们刚发布了划时代的产品麦金塔电脑，而乔布斯刚满三十岁。然后，**他被自己创立的公司解雇了**。

随着公司壮大，他们聘请了一位他认为是天才的人来共同管理公司。起初一切顺利，但后来两人对未来的愿景出现分歧，最终闹翻。董事会站在了那个人一边。三十岁的乔布斯，被公开地驱逐了。

他形容那感觉是“毁灭性”的。他成了公众眼中失败的典型，甚至想过逃离硅谷。有几个月，他完全不知道要做什么，觉得自己让上一代企业家失望了，像弄丢了传递过来的接力棒。

但慢慢地，一个念头开始浮现：**他依然热爱他所做的一切。** 苹果公司发生的事，丝毫没有改变这份热爱。他被拒绝了，但他仍然爱着。于是，他决定重新开始。

后来他意识到，**被苹果解雇是他人生中发生的最好的事情**。成功带来的沉重感，被重新开始的轻盈感所取代。他不再对一切那么确定，这让他进入了生命中最富创造力的阶段之一。

接下来的五年，他创立了NeXT公司，又创立了皮克斯动画公司，并爱上了一位卓越的女性，后来成为他的妻子。皮克斯制作了世界上第一部电脑动画长片《玩具总动员》，如今已是全球最成功的动画工作室。而命运发生了奇妙的转折：苹果收购了NeXT，乔布斯重返苹果，他在NeXT开发的技术成为了苹果日后复兴的核心。他也拥有了美满的家庭。

他确信，如果当初没有被苹果解雇，这一切都不会发生。**这剂药很苦，但病人需要它。**

有时候，生活会给你当头一棒，但不要失去信念。乔布斯深信，支撑他走下去的唯一原因，就是他热爱他所做的事。所以，你必须找到你所爱的东西。**工作如此，爱情亦如此。** 你的工作将占据生活的很大一部分，而唯有从事你认为是伟大的工作，你才能真正获得满足。而成就伟业的唯一途径，就是热爱你的事业。

如果你还没找到，**继续寻找，不要停下，不要将就。** 就像所有关乎内心的事情一样，当你找到时，你自然会知道。而且，就像任何伟大的关系一样，随着岁月流逝，它会越来越好。所以，继续找，别将就。

**第三个故事：关于死亡**

十七岁时，乔布斯读到一句话：“如果你把每一天都当作生命中的最后一天来过，总有一天你会发现你是对的。”这句话深深影响了他。在之后的三十三年里，他每天早晨都会对着镜子问自己：“如果今天是我生命的最后一天，我还会去做今天原本要做的事吗？”如果连续太多天的答案都是“不”，他就知道需要做出改变了。

**“记住你即将死去”，是乔布斯用来帮助做出人生重大抉择的最重要的工具。** 因为几乎所有一切——所有外界的期望、所有的骄傲、所有对难堪或失败的恐惧——在死亡面前都会烟消云散，只留下真正重要的东西。记住你终将死去，是避免陷入“害怕失去”这个陷阱的最好方法。你已经一无所有，没有理由不去追随你的内心。

大约在演讲的一年前，乔布斯被诊断出癌症。早上七点半的扫描显示，他的胰腺上有一个肿瘤。他当时甚至不知道胰腺是什么。医生告诉他，这几乎是不治之症，预计他只剩三到六个月的生命。医生建议他回家，把一切安排妥当，这其实是“准备后事”的委婉说法。

他整天都活在那个诊断的阴影下。当晚，他做了活检。后来妻子告诉他，当医生在显微镜下观察细胞时，他们哭了，因为那是一种非常罕见的、可以通过手术治愈的胰腺癌。他接受了手术，现在康复了。

**这是乔布斯最接近死亡的一次**，他希望这也是未来几十年内最近的一次。经历过这次，他可以更有把握地说出下面这些话，而不只是停留在理论层面：

没有人想死。即使是想上天堂的人，也不想通过死亡到达那里。然而，**死亡是我们所有人共同的终点，无人能逃。** 这其实是件好事，因为死亡很可能是生命最伟大的发明。它是生命的变革推动者，它清除旧物，为新生代让路。现在的新生代就是你们，但不久的将来，你们也会逐渐变老，被清除出去。

**我们的时间有限，所以不要浪费时间活在别人的生活里。** 不要被教条束缚，那意味着你在活在别人思考的结果里。不要让他人的意见淹没了你自己内心的声音。最重要的是，**要有勇气追随你的内心和直觉。** 它们早已知道你真正想成为什么样的人。其他的一切都是次要的。

乔布斯最后分享了一个来自他青年时代的灵感源泉：《全球概览》杂志。在它停刊的最后一期封底，是一张清晨乡间小路的照片，下面有一行字：**“Stay Hungry. Stay Foolish.”**（求知若渴，虚怀若愚）。这是他们的告别寄语。乔布斯一直以此自勉。现在，在毕业生们即将启程的时刻，他也把这句话送给大家：

**求知若渴，虚怀若愚。**

（音乐渐起）
