# 如何从零开始建立你的受众（只需两个习惯）

好吧，我接下来要说的话可能听起来有点自负，但在社交媒体上成长其实很简单。我是认真的，我不只是为了吸引眼球才这么说。这确实是个好标题，但我是真心这么认为的。我在任何平台上都没有遇到过成长问题。

所以当我构思这个视频的时候，我问自己："好吧，为什么对我来说成长这么容易？"这其实源于我在开始做社交媒体之前，已经失败了七次不同的商业模式。所以当我开始做社交媒体时，我并不是从零开始的。我已经掌握了一大堆高价值技能，尽管之前的那些生意——因为"新奇事物综合症"——都失败了。

我尝试过太多不同的事情。我试过用Photoshop做数字艺术。我试过摄影，做付费的人像拍摄。我试过多个代理业务，比如Facebook广告、SEO、网页设计。我试过两次代发货。我试过建立一个电商品牌——其实基本上就是代发货做了两次。可能还有一些我都不记得了，因为它们持续的时间太短了，每次大概就一周。我会开始做一件事，然后建网站，兴奋地注册公司，然后多巴胺消退，我就放弃了。

这挺不幸的，因为作为青少年，不知为什么，找一份朝九晚五的工作对我来说就像是一种诅咒。我环顾四周，看着我的父母——我爱我的父母——但我看着老一辈的人。你去沃尔玛，环顾四周，看到那些人，你会想："这不是我想要的结局。"当我反过来思考"是什么导致了他们这样的生活"时，在我青少年时期的想法里，那就是朝九晚五的工作。它占据了你一天大部分的时间。你晚上回家，累得要死，根本没有时间去做真正有意义的事情。

所以我想做一些有创意的事情。我不想做朝九晚五的工作，我想做有创意的事情。我确实上了五年大学，但我把它当作一个缓冲期，用来尝试各种事情。我在高中是全优生，但在大学里，我就是那种"及格万岁"的人。五年大学，不断换专业——这大概就是我青年时期的主题，我猜——就是不断地转换方向。我不断改变，犯错误，调整方向，做实验。这给了我很多经验，但也给了我很多失败。

那时候，我大概欠了两万美元的学生贷款，而且还在不断增加。出于紧迫感，说实话也是因为害怕自己无法生存，我开始找工作。我在一家网页设计公司找到了一份工作，因为我之前已经掌握了这个技能。那份工作挺轻松的。我继续学习如何做自由职业。我一边做网页设计，一边可以看到我所在的公司内部是如何运作的。我大致明白了如何以正确的方式开始做自由职业。

于是我开始做自由职业。长话短说，在六、七、八个月的时间里，它开始有了起色。工作了九个月后，我辞掉了工作，因为我对自己的自由职业有了足够的信心。不过自由职业其实只是美化了的朝九晚五。你仍然在为别人工作，做不属于你的项目，很可能还是你根本不在乎的项目，没有任何创意方向。但这并不是重点——实际上，这恰恰是我开始做社交媒体的原因。

我也不知道为什么，我居然在Twitter上刷着，看到有其他网页设计师在讨论我的兴趣。那些网页设计师只是在分享一些基础建议，比如"如果你想辞职，需要学习的十大技能"。当时这引起了我的共鸣。他们通过这种方式获得了网页设计的客户，还卖关于如何做网页设计、如何做自由职业的课程。我想："我也可以做同样的事情。他们说的那些东西我都知道怎么说，而且他们做得很好。为什么我不能像他们一样？"

所以我开始在社交媒体上发帖。但我的优势——以及我一开始就能持续增长的原因——并不是一下子就飞速增长的。大概是头两个月每周增加100个粉丝，然后增加到每周500个，最后稳定在每月2000个粉丝左右。中间也有波动，有时一条推文爆了，粉丝数会大幅增长，然后又会回落到每月1500到2000的稳定增长。

我之所以能做到这一点，是因为我在数字艺术上的失败在一定程度上教会了我品牌美学。所有技能的获取其实都是模式识别。所以并不是说我在Twitter增长的时候还在练习或使用那些技能。更多的是，我因为失败而积累了大量的经验，所以从一开始我就对"什么是一个好的标题"有更好的品味——因为我研究过Facebook广告和文案写作。当我尝试做那些代理业务时，我做过一些冷启动的客户开发。我知道如何建立人脉，知道如何发私信，知道如何交朋友，知道如何先提供价值，这样他们才会回报价值——这部分我们稍后会在视频中详细讲。

我做的网页设计，加上文案写作，再加上品牌打造，这些配合得很好。所以当涉及到学习如何创建数字产品，或者创建比大多数初学者更好的数字产品时，我有一个更好的起点。因为大多数人在开始做社交媒体时，那是他们的第一次尝试。所以他们一边做一边学习技能，同时慢慢培养品味——这恰恰就是让你陷入"新手地狱"的原因。

"新手地狱"就是你发帖就像对着虚空喊话，根本得不到任何粉丝。通常，如果你不纠正错误，不关注什么有效什么无效，不进行方向调整和迭代，你就永远不会有突破。这就是为什么大多数创作者——我不怪他们——会放弃，因为他们就是无法获得任何进展。

所以这就是我制作这个视频的目标。社交媒体是一个非常可行的商业模式，尤其是对一个人来说，尤其是在有AI辅助的情况下。在当今世界，你可以创造出很多很酷的东西。但前提是你拥有能让你脱颖而出的技能。因为大多数人的做法是："哦，我需要发内容。哦，我需要用AI做点东西。"每个人都在这么做。如果每个人都这么做，那就没有人能成功。是的，AI给了你超能力，但当每个人都有超能力时，就没有人有超能力了。

所以，再说一次，这就是我的目标。你无法避免失败，无法避免错误，无法避免积累经验——那些导致模式识别、进而导致技能获取的经验。但我可以告诉你的是，你需要关注的两个杠杆，它们能让你在社交媒体上增长得更快，也能帮助你更快地进行模式识别。

我的第二个目标是向你证明，社交媒体不是靠算法运气。你不是随便发帖然后祈祷算法选中你，然后在失败时把责任推给算法和你自己的技能不足。社交媒体就像电子游戏。很多事情都像电子游戏。它们有特定的机制和杠杆，你可以学习并运用。当你在游戏中达到更高等级时，你就能看到全局。你已经经历了所有机制，已经升级了所有能力，剩下的就是发挥创意。

但当你成为某个领域的专家时，你往往更容易患上"新奇事物综合症"，需要更专注。所以作为初学者，你实际上有一个优势——因为那些非常擅长社交媒体的人也往往会衰落。你会看到很多大YouTuber或者其他人减少产出。我最近也减少了产出。而这为新创作者创造了空间。

所以，两个杠杆。这就是我们需要知道的。把其他一切都视为干扰。真的，只专注于这两件事。不要分心。专注于这两件事，你会做得很好，我保证。

**第一个杠杆：从你自己的角度做那些已经有效的事情。**

这听起来可能不那么厉害，但我保证这就是秘诀。如果你真的把它当作优先事项，它就会成为优先事项。因为初学者创作者的一个大问题是，他们总是想："哦，我没有什么新东西可以说。"好像人们上社交媒体是为了看新东西一样。不是的。如果你真的思考一下你自己是如何消费社交媒体的——或者我是如何消费的——人们上社交媒体是为了看某个特定创作者对已经有人在讨论的话题的看法。这就是算法的工作方式，尤其是在YouTube上。

如果你看了一个关于某个话题的视频，YouTube就会向你推荐另一个创作者做的同一个话题。如果你理解了这一点，你就会明白：如果你制作了一个和已经表现很好的视频相似的视频，那么你就会被推荐给那些看过那个好视频的人。我稍后会详细解释，但我希望这一点能真正印在你脑子里。这就是YouTube增长的精髓。其他所有课程、所有策略都是次要的。它们有用，但都是次要的。

这也符合我自己的消费习惯。我可以每天看到同一个视频标题，来自不同的创作者，我大概还是会看。我确实会看，因为我想听他们的观点。每个人都在谈论Claude Code、Claude、OpenAI，所有这些关于未来工作的东西。当我陷入想要了解某个话题的兔子洞时，我会反复看同一个话题，这样我就能掌握所有细微之处，完全理解它。健身视频也一样。我热爱健身，说实话那才是我的首要任务，这些都已经变成次要的了。但如果我每看一次营养学入门视频或者某个创作者对营养的看法就能长一块肌肉，我现在已经是Ronnie Coleman了。

这是任何平台上社交媒体增长最根本的一个方面。我们来看看Craig Perry这个人，他完全在照搬我的方法。我不知道他是不是从我这里学到的，但他的YouTube简介上写着"对着镜头读我的newsletter"。我刚刚打开我的newsletter，我不是逐字逐句地读，而是把它当作一个可以发挥的大纲。看看他的前两个YouTube视频，是真正的第一个和第二个视频。你看到了吗？23万次观看和14.4万次观看。这简直太离谱了。你几乎看不到有人能在YouTube频道的前两个视频就取得这样的成绩。这恰恰证明了我在说什么。他是不是有点运气？也许吧。如果你一比一地复制这些视频，你会得到同样的结果吗？也许，也许不会。我不知道。但我只知道，如果你这样做足够多次，你就会开始看到一波波互动和粉丝的增长。
