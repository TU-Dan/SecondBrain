接下来，## 前沿智能的本质与规模化探索

在人工智能的前沿领域，智能的本质是关于**外推和规模化损失**。所以，基本上，你会在较小的模型上进行大量的探索，然后尝试将结论外推到更大的规模。

## 研究效率的提升与自动化

**所以你的意思是，我们的研究工作会变得更高效，就像我们在规模化时也会有更好的方向指引，前提是能更好地进行这种实验？**

是的。我想说，最有趣的项目，很可能也是那些前沿实验室正在攻关的，就是你在小模型上进行实验，尝试让它尽可能**自主化**，将研究人员从循环中移除。他们拥有太多……太多什么来着？相反词是什么？**太多自信了**。是的，他们其实并不知道，他们真的不应该插手这些事。

所以你必须重新构建整个体系。因为现在，他们当然可以贡献想法，但他们不应该亲自去实施这些想法。应该有一个想法队列，可能还有一个**自动化科学家**，它能基于所有存档的论文和GitHub仓库提出想法，然后将想法汇集进来。研究人员也可以贡献想法，但只有一个单一的队列，然后有“工人”从中提取任务进行尝试。那些有效的想法就会被放到功能分支上，可能有些人会监控功能分支，并有时将其合并到主分支。

所以，是的，就是**将人类从所有流程中移除，并尽可能实现自动化**，获得高吞吐量（每秒处理大量令牌）。这确实需要重新思考所有的抽象概念，一切都必须重新洗牌。所以，我认为这非常令人兴奋。

## 递归思考：模型何时超越我们？

**所以，是的，没错。你需要某种自动研究循环，也许你可以想象不同的程序MD会给你带来不同的进展。基本上，每个研究组织都是由程序MD描述的。**

**一个研究组织就是一组描述所有角色以及整个系统如何连接的Markdown文件。**

嗯，你可以想象拥有一个更好的研究组织。也许他们早上开的站会更少，因为那些站会没用。而这一切都只是代码，对吧？所以，一个组织可以有更少的站会，另一个组织可以有更多的……一个组织可以非常敢于冒险，另一个则可以更保守。因此，你完全可以想象拥有多个研究组织。它们都有代码，而一旦你有了代码，你就可以想象去调整这些代码。所以，**百分之百存在一个元优化层**。

## 模型的“粗糙边缘”与智能的“锯齿状”

**嗯，因为这些模型仍然……你知道，它们已经改进很多了，但它们仍然像是边缘粗糙——也许这是我能想到的描述方式。**

我同时感觉像是在和一个极其聪明的博士生交谈，他一生都像是系统程序员，同时又像一个10岁的孩子。这很奇怪，因为人类……我觉得他们更协调一致。你知道，你不会遇到那种组合。

**这种“锯齿状”真的很奇怪，人类身上这种“锯齿状”要少得多。虽然他们肯定也有一些，但人类……抱歉，是智能体有更多的“锯齿状”，有时候，你知道，我要求某个功能，它返回的东西完全错了，然后我们陷入完全错误的循环，我经常对智能体感到非常沮丧，因为你感受到它的力量，但它仍然时不时地做一些无意义的事情，对我来说也是如此。**

**当我觉得智能体浪费了大量计算资源在它本应能识别出的明显问题上时，我会非常恼火。**

**是的，我认为，如果让我假设的话，一些更大的问题可能在于其根本：这些模型是通过强化学习训练的。所以它们实际上正在与我们刚刚讨论的完全相同的问题作斗争，那就是实验室可以在任何可验证的、有奖励的方面改进模型。所以，你写的程序正确吗？单元测试通过了吗？是或否？但它们在某些方面仍在挣扎，例如，我认为它们在处理细微差别方面有困难，比如我原本的意图是什么，我打算做什么，以及何时提出澄清问题。**

**嗯，任何感觉上更“软性”的东西，表现就更差。所以你有点像……你要么在轨道上，成为超级智能电路的一部分；要么不在轨道上，处于可验证领域之外，然后一切就有点漫无目的了。**

## 智能的“解耦”与“锯齿状”的启示

**你认为这是否意味着我们没有看到……比如更广泛的智能的泛化，讲笑话的聪明程度与写代码的聪明程度是关联的？**

**但是，我的意思是，一些研究团队的前提是，如果你在代码生成或这些可验证领域更聪明，你应该在所有事情上都更聪明。而讲笑话的情况表明，这并没有在所有领域发生。**
